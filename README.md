# CaltuboWen

A simple web application for calculating tube measurements.

## Local Development

To run this project locally, you can use a simple HTTP server. If you have Python installed, you can run:

```bash
python -m http.server
```

Or with Node.js, you can use `serve`:

```bash
npm install -g serve
serve .
```

## Deployment

This project is configured for automatic deployment to GitHub Pages. Any push to the `main` branch will trigger a GitHub Actions workflow that deploys the application.
